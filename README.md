## 🐍 &nbsp;Shadow Moves

<div align="center">

<br/>

<img src="https://raw.githubusercontent.com/shubham17290/shubham17290/output/snake.svg" alt="Snake Animation" />

<details>
<summary><b>⚙️ &nbsp;Enable Snake Animation (one-time setup)</b></summary>

<br/>

Create `.github/workflows/snake.yml` in your **profile repo** and paste:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/snake.svg
            dist/snake-dark.svg?palette=github-dark
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: dist
          publish_branch: output
```

Then run **Actions → Generate Snake Animation → Run workflow**. ✅

</details>
